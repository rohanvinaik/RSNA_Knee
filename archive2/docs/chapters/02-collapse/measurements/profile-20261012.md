## What it says

1. **One instance of the audit's class, and it is not a recomputation: it is a scalar loop on the
   kernel path.** The bundles' through-plane bank, the slab rule's first consumer, calls the scalar
   `slab_code` once per claimed place per other acquisition. On the real study that is 1.9 million
   Python calls and half of `run_study`'s time. The builder's own contract said this was the
   reference's honest bound and that no vectorised twin existed. The house rule is reference first,
   then a twin that answers to SAME; the twin is owed. Declared as task 7.10.
2. **No stage recomputes another stage's work.** Every per-series function runs five times (five
   series), `read_member` and `place_codes_reference` ten times (two seated populations),
   `read_ownership` fifteen (three members), `sample_profiles` fourteen (five interiors, four
   exchanges, five pairings), each on different inputs. The regime key is read once per series and
   consumed from the record.
3. **The writer's compression is a quarter of the wall time** with pictures off, outside the route.
   It is the artifact's cost, not the analysis's; nothing is declared about it.
4. **Import is 0.6 s**, mostly SciPy and scikit-image behind `regime` and `interiors`.

Not measured: memory (`just memory`), the drawing pass (pictures were off), and the Kaggle
