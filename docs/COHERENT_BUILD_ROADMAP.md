which producer owns it; which later decision consumes it; which native region is visited; and
what uncertainty remains. These links live in the existing functions, typed records and ledger,
not a second hand-maintained execution engine.

## 6. Worker automation and integration discipline

The lead owns human intent, anatomical interpretation, choice of lenses, visual acceptance and
the one production writer. Cheaper workers receive these decisions; they return facts, code or
artifacts under a bounded contract. They do not supply the meaning of the task.

Automate these repeatable jobs:

- **Object/view inventory:** reconstruct the native/laid/read/projected/refused rows from the
  actual receipts, separate native readings from resolved supports, validate source addresses,
  and compare selected map orientations with the available native evidence. No clinical verdict.
- **Native-frame inspection packets:** reconstruct actual DICOM frames, source locations, rough
  windows and candidate supports; save the generator, crop offsets, hashes and measured work.
- **Mechanical implementation:** after the lead has chosen the anatomy/lens combination, implement
  a small helper or one family adapter in explicitly owned files and add meaningful tests.
- **Integration audit:** compare earlier observation/refusal prefixes, saved arrays and changes to
  guidance; reconstruct new supports, check serial/parallel outputs and read the full gate report.
- **Cohort measurement:** after a family wave, run the single entry point and calculate actual
  pair-vector ranges/sample SD, with unknown SD retained where samples are insufficient.

Use small local Codex workers first. Workers use whole-unit AST reads or a scoped read-only map,
not additional Serena servers. Do not give multiple workers the orchestration file. Parallelize
independent evidence generation and audits, not competing edits to shared producers. Before a
real verification run, freeze relevant production source and retain its hashes; keep failed and
corrected runs separately.
