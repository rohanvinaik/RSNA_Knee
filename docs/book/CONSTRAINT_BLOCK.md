## The thesis in one breath

A classical-AI data-geometry system reads a knee MRI study the way *What an \<Object> Is* reads cells. With **no
machine learning anywhere**, it:
- registers the study into a platonic knee's frame;
- compares every place against report-negative normal knees;
- delineates each structure in the patient's own anatomy;
- lets questionless lenses measure what deviates;
- explains objects in rounds;
- has a society of agencies decide each of the 12 findings by concurrence of independent acquisitions, or
  abstain.

It is built as one fresh, SICP-organized, Detective-pinned codebase. Each operation is in its best language:
Python decides; NumPy, SciPy and SimpleITK do whole-array work; Numba JIT runs the hot loops; native code enters
only by evidence.
