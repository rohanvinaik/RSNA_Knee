## Claims from the response not adopted

* "The chain must be permitted to terminate" at accounted-for neighbor material:
  this is not a universal knee law. A neighboring object may constrain a shared
  interface rather than end a target's contour. Peer membership, containment,
  acquisition mixtures and the actual boundary question have to be distinguished.
* Removing accounted-for support: scoped search exclusion is useful, but neither
  the shared source samples nor every other question's support disappears.
  The cell `REMOVED`/`SET_ASIDE` distinction demonstrates why one global consumed
  mask is insufficient.
* Fable puts sampler SAME disagreement and changing axial sections in a category
  headed measurement availability. SAME disagreement is an implementation defect
  to investigate; changing anatomy across sections is observed content. Neither
  automatically means the scanner failed to acquire a reading.
* "Alignment from acquisition metadata": metadata supplies coordinate mappings,
  not proof of cross-acquisition registration. The reference coordinate relation
  and measured anatomical correspondence remain distinct.
* Restricting the first increment to open/disagreement with no identity call is a
  consultant suggestion, not a founder restriction. A claim that has a genuine
  domain warrant should be used confidently, as the founder and thesis require.
