# Proposal

## Why

Chapter 2 needs a traceable physical measurement foundation before anatomical object boundaries can be resolved. Packet A establishes the DICOM frame, coverage-aware squints, native profiles, and an exact reference/JIT contract that later packets can consume without turning measurements into anatomical decisions.

## What Changes

- Add Packet A contracts for patient-space plane geometry, physical squints, native profiles, support codes, read-once production measurement, and measurement receipts.
- Establish the Python reference and Numba twin contract, explicit backend refusal, immutable measurement records, and same-environment SAME behavior.
- Add a development-only Hamilton graph over the same production measurement functions, plus observable receipts, profiles, rendering, and telemetry.
- Add B1 geometric interior distance, all proposed territories, directed edges and native dark-band readings using the existing surrounding-field split, retaining unresolved and unclaimed material.
- Produce separate color stage series and bind source records, checkpoints, SAME and photo manifests.
- Continue with B2's general conversation between same-orientation readings of the same knee, then supported contour chains, facing surfaces/interstitial extent, peer ownership and residual scheduling. The founder's coronal example illustrates the operation; it is not a hard-coded pair rule. The thesis and live cell build guide the general mechanism.

## Capabilities

### New Capabilities

- `physical-measurements`: Defines the observable physical frame, squint, native profile, support, and production measurement behavior for Chapter 2 Packet A.
- `geometric-interiors`: Defines surrounding-field constraints, all geometric territories, native dark-band evidence and production-backed staged pictures for B1.
- `same-knee-conversation`: Declares the continuing B2 contract for cross-resolution of independent readings of shared objects, retaining native evidence and disagreements.

### Modified Capabilities

None.

## Impact

The change affects Chapter 2 source and production callers, new intent and property tests, development graph and profiling configuration, and the optional Numba dependency. Private measurement outputs remain in ignored data artifacts; competition data is not redistributed.
