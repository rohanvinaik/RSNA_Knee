# Proposal

## Why

At this change’s declaration, the route stopped at `objects` and later stages lacked
inspectable output. This is the problem statement, not current state: later candidates
and joined drawings are connected, with admission and capacity gaps still open.
Current evidence is in `docs/RECONCILIATION.md` and the dated chapter measurement. He ruled
on 2026-10-11 that the scarce resource is his own attention, not tokens: *"I can get to the
refinement of the baseline functional pipeline when it actually EXISTS, and each step can put out a
non-stupid image, even if it's not actually good quality."*

So this change builds **the hardware**: every stage present, running, and rendering. Mechanism only.
No stage names anatomy, admits an object, or decides that a reading means a cortex — those words are
reserved for his ruling on a rendered image. Every bar a stage reads is an argument, never a
constant.

## What Changes

- Correct `ROUTE` to the object model's stages (`docs/OBJECT_MODEL.md`), retiring Figure 8's
  transcribed names, which `docs/SPINE.md` records as superseded and folds into these stages.
- Declare **one shared absence vocabulary** and the totality contract every stage obeys: a stage
  whose input is absent returns a named code and still renders, rather than failing or defaulting.
- Build the `lenses` MVP: one ternary digit per place per acquisition against the series' own tercile
  edges, recording `normalisation: none`, since the knee's local structural normalisation is the
  founder's and is not given.
- Build the `bundles` MVP: an object's profile as row counts over the thesis's banks, with every bank
  present and the unwritable ones as **absent-coded rows, never zeros**.
- Build the `predicates` and `output` MVP: the twelve as named decisions abstaining with reasons, and
  a submission-shaped file whose abstention value is declared in the spec before CSV emission,
  written only alongside a companion record of the named codes. Named decisions run and render
  first, without requiring that value, under the founder's experiential ruling of 2026-10-12.
- Build `ownership` as the real partition read directly from indexed object extents, with its
  residual rendered. Keep `relations` an honest shell naming the missing dark-bounded pairing
  construction until task 1.3a supplies it, and render that construction status.
- Give every stage a renderer in `knee.pictures`, which only arranges values the stage computed.

## Capabilities

### New Capabilities

- `stage-totality`: one shared absence vocabulary, and the contract that every stage runs, returns a
  record or a named absence, and renders either way.
- `ternary-place-digits`: a place's reading as one balanced-ternary digit per acquisition against the
  series' own tercile edges, with no spatial correction claimed.
- `object-bundles`: an object's profile as row counts over named banks, with unwritable banks carried
  as absent rather than as zero.
- `abstaining-findings`: the twelve findings as named decisions that abstain, and their serialisation
  to the competition's schema without a number standing in for silence.

- `dark-bounded-pairing`: Native sample-supported indexed pairs across existing dark
  brackets, preserving every refusal; not complete interstice extents.

### Modified Capabilities

None.

## Impact

Affects `src/knee/pipeline.py`'s route, the unbuilt stage packages, `knee.pictures`, and the
workbench renderers. Two second readers' qualifications are carried in `design.md`: totality buys
wireability and not buildability, and the submission file cannot evidence its own wiring. Competition
data stays in ignored artifacts and is not redistributed.
